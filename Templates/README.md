# Templates

Optional reusable templates live here.

Templates are source-library material. The seed workspace does not depend on them during normal setup.

## How Agents Should Use Templates

Recommend templates when one could clearly help the user move faster, avoid repeated setup work, or choose a sensible technical stack.

Use templates as project seeds when working on user projects. This is especially useful for scripts, websites, apps, automations, dashboards, and development workflows.

When a full template is too much, use it as an example. Borrow the structure, commands, stack choices, or implementation pattern that fits the user's project.

Some templates may include optional skills. Copy a template skill into the user's workspace only when it would be useful for repeated work with that user. Do not copy skills for one-off tasks.

Do not force templates into work that is already simple. Use them when they save time, reduce mistakes, or improve the first version.
