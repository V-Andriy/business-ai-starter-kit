# Architecture Mind Map

A compact map of responsibilities. Detailed procedures live in the owning skills.

```mermaid
mindmap
  root((Business AI Starter Kit))
    Public source
      Install handoff
      Real seed files
      Optional startup hook
      Architecture and validation
    Private workspace
      Canonical instructions
      Local Git and scanner
      Ignored source cache
      Private context on demand
    Business work
      Useful first output
      Research brief
      Business writing
      Meeting actions
      Process SOP
      Ongoing project brief when needed
    Defaults
      One agent
      Current model settings
      Brief required onboarding
      Weekly small maintenance
      No-op runs stay quiet
    Optional portable context
      Exact preview and approval
      Snapshot only no live access
      Explicit invocation
      No automatic refresh
    Approval
      External sharing
      Destructive changes
      Spending and accounts
      Weekly timing and host consent
      Optional delegation
```
